RooiWolf — iPhone-friendly frame quotation calculator

PACKAGE CONTENTS
- index.html: frame quotation calculator and saved estimates
- manifest.webmanifest, sw.js, icons: installable/offline-capable web app files

USE ON YOUR COMPUTER
1. Extract this ZIP.
2. Open index.html in Chrome, Edge or Safari.
3. Enter quantity, choose Standard frame or Floater frame, search/select a moulding code, enter length and width in millimeters, and select the labour size. For standard frames also choose mounting style.
4. Add frame items, enter optional customer details, then save the estimate or print/save as PDF.

ADD YOUR LOGO
In the header, choose your PNG/JPG logo. It is saved in that browser on that device. The image is kept in its original proportions and displayed centred.

USE AS AN APP ON iPHONE 13
The ZIP is the app package, not an App Store installation or a hosted web address. To install it on iPhone, first publish all files in this folder to a free HTTPS static host (for example GitHub Pages). Then open that HTTPS address in Safari, tap Share, and choose Add to Home Screen. The app can then open in standalone mode and cache its app files for offline use after the first successful load.

FREE GITHUB PAGES STEPS
1. Create a public GitHub repository named rooiwolf.
2. Upload every file in this folder to the repository root (not just index.html).
3. In Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
4. Open the published Pages URL in Safari on the iPhone and Add to Home Screen.

QUOTE STORAGE
Saved estimates and selected logo are stored locally in the browser on that device. They do not sync automatically to another phone/computer. Print / Save as PDF to keep or share a quote.

PRICING / FORMULA BASIS
The moulding codes, descriptions and prices and the calculation rates are embedded from the supplied workbook. Rates: glass R485/m²; MDF R110/m²; Edge-to-Edge R150/m²; Raised-and-Floated R323/m²; spray paint R35/linear metre; fittings etc. R55/m²; labour R550 multiplied by the selected size bracket. Standard linear length = quantity × (length + width) × 2.4; area = quantity × length × width.
